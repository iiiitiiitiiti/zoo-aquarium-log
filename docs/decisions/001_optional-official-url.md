## 001. 公式サイトが無い施設は url を省略し、ボタンを出さない

- 日付: 2026-10-19
- 対象: `src/data/facilities.json` の `url`、詳細画面の「公式サイトを見る」ボタン、`scripts/validate-facilities.mjs`

### 決定

施設マスタの `url` を任意にした。公式サイトが確認できない施設は `url` を書かず、詳細画面にボタンを出さない。空文字 `""` は不正として検証で弾く（省略と区別するため）。営業の裏づけは `sourceUrls` と `note` で示す。

### 背景

2026年10月の月次監査で、ダチョウらんど沖縄の公式ドメイン dacyou.net が失効し、無関係なサイトへ転送されていると分かった。代わりの公式サイトは見つからなかった。一方で2026年3月の来園の口コミがあり、施設は営業を続けているとみられた。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 施設ごと削除する | 営業は続いているとみられる。全施設収録という目標に反する |
| 地図サービスや観光サイトのページを url に入れる | ボタン名「公式サイトを見る」と中身が食い違う |
| 失効したドメインのまま残す | 無関係なサイトへ利用者を送ってしまう |

### 影響範囲

- 手動追加の施設は、以前から url が空になりえた。同じ修正で、空のリンクが出る問題も消えた
- 月次監査は url の無い施設を検査対象にしない（`sourceUrls` は検査する）
- 公式サイトが復活したら `url` を足し直す

### 検証

`src/VisitPanel.test.tsx` と `tests/facilities.test.mjs` に、url の有無と空文字のテストを足した。url 省略の施設でボタンが出たら、この判断が崩れている。
