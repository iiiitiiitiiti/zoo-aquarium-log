## 1. 端末・実行形態

可能な範囲で、次の組み合わせを確認します。

- [ ] iPhone / Safari（ブラウザ）
- [ ] iPhone / ホーム画面に追加したPWA（スタンドアロン）
- [ ] Android / Chrome（ブラウザ）
- [ ] Android / ホーム画面に追加したPWA（スタンドアロン）
- [ ] Wi-Fi接続時
- [ ] モバイル回線時

確認時に記録する情報:

- 端末名・OSバージョン
- ブラウザ名・バージョン
- ブラウザ表示か、ホーム画面から起動したPWAか
- Wi-Fiかモバイル回線か

## 2. 起動・PWA

- [ ] URLを開くと白画面や無限ローディングにならず、ログイン画面が表示される
- [ ] ページを再読み込みしてもアプリが正常に起動する
- [ ] iPhoneでホーム画面に追加できる
- [ ] Androidでホーム画面に追加できる
- [ ] ホーム画面のアイコン・アプリ名が正しく表示される
- [ ] ホーム画面から起動すると、ブラウザのアドレスバーなしで表示される
- [ ] ノッチ・ステータスバー・画面下端のホームインジケータにUIが隠れない

- [ ] 更新がある場合、更新通知から「後で」を選んでも現在の画面が壊れない
- [ ] PWAを終了して再起動しても、ログイン状態と設定が保持される

## 3. ログイン・世帯データ同期

## 10. アニメーション設定・iPhone視差効果

アプリの設定とiPhoneの「視差効果を減らす」を組み合わせて確認します。アプリの既定値はアニメーション表示です。

- [ ] 初回利用時、アニメーションが表示される
- [ ] アプリ内設定でアニメーションをOFFにできる
- [ ] OFFにすると、画面の開閉・フェード・移動などのアニメーションが停止する
- [ ] OFFの状態を再読み込み後も保持する
- [ ] OFFの状態をPWA再起動後も保持する
- [ ] アニメーションをONに戻すと、再び表示される
- [ ] iPhone「設定 > アクセシビリティ > 動作 > 視差効果を減らす」をONにしても、アプリ設定がONならアニメーションが表示される
- [ ] iPhoneの視差効果設定に関係なく、アプリ設定がOFFならアニメーションが表示されない
- [ ] 地図のズーム・フェード・マーカー・クラスタ・慣性・プログラム移動も、アプリ設定OFF時に停止する
- [ ] 地図のアニメーションをOFF/ONに切り替えても、中心位置・ズーム・開いていたポップアップが不自然に失われない
- [ ] 設定変更後に一覧、訪問記録、地図の操作が継続できる
